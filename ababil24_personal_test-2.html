فرم آزمایشی شخصی ابابیل ۲۴

این فایل مستقل برای آزمایش ذخیره اطلاعات در Cloudflare D1 است. با فرم رسمی و سامانه‌های شرکت ارتباطی ندارد.

🔒 فقط اطلاعات ساختگی وارد کنید. API فعلی هنوز برای دریافت اطلاعات واقعی مشتریان از نظر کنترل دسترسی و جلوگیری از سوءاستفاده بررسی و ایمن‌سازی نشده است. این فایل جایگزین فرم فعلی GitHub شما نیست.
ارسال آزمایشی مستقیماً به Worker شخصی شما انجام می‌شود؛ هیچ پیام واتساپی ارسال نمی‌شود.
